# Stunet - Student Management Platform

A modern, high-performance web application for student management, college discovery, and resource sharing.

## 🚀 Features

- **Modern Glassmorphism UI**: Premium design with full Dark/Light mode support.
- **College Discovery**: Browse, filter, and track engineering colleges.
- **Resource Sharing**: Community-driven repository for notes and question papers.
- **Stunty AI**: Intelligent assistant to help with admissions and platform navigation.
- **CAP Rounds Tracking**: Keep track of admission rounds and cutoffs.
- **Fully Responsive**: Optimized for Desktop, Tablet, and Mobile devices.

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite
- **Styling**: Vanilla CSS with Design Tokens
- **Icons**: Lucide React
- **Backend (Ready)**: Supabase Integration (with fallback to LocalStorage)
- **Deployment**: Vercel

## ⚙️ Setup & Installation

1. **Clone the repository**
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Set up Environment Variables**:
   - Create a `.env` file based on `.env.example`.
   - Add your Supabase URL and Anon Key.
4. **Run locally**:
   ```bash
   npm run dev
   ```

## 🌐 Deployment (Vercel)

1. Push your code to a GitHub repository.
2. Connect your repository to [Vercel](https://vercel.com).
3. Add your Environment Variables in the Vercel project settings.
4. Deploy!
